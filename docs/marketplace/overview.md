# WorkVouch for Greenhouse — Marketplace Overview

WorkVouch Connect brings verified employment, trust scores, and hiring confidence directly into Greenhouse — so recruiters evaluate candidate quality without leaving their ATS.

## Value Proposition

- **Hiring Confidence** — one clear 0–100 score with full explainability
- **Verified employment** — manager and coworker reference consensus
- **Embedded panel** — native Greenhouse sidebar experience
- **Automation** — invite candidates at configurable lifecycle triggers
- **Diagnostics** — one-click support bundle for troubleshooting

## What It Does

1. Connects via OAuth (Greenhouse Harvest)
2. Receives real-time webhooks (Hookshot)
3. Links candidates by email to WorkVouch profiles
4. Displays trust + verification in embedded panel
5. Automates verification invitations based on employer rules

## What It Does Not Do

- Does not make hiring decisions automatically
- Does not store city/ZIP/GPS location data
- Does not modify Greenhouse candidate records without explicit sync configuration
- Does not replace Greenhouse workflow

## Target Users

- Recruiters reviewing candidates in Greenhouse
- Hiring managers needing verification confidence
- TA ops configuring automation rules
